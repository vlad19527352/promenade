# Променад — экскурсии по Светлогорску

Одностраничный лендинг экскурсионного агентства: расписание четырёх прогулок, расчёт стоимости и заявка на почту владельца.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Разметка страницы |
| `styles.css` | Стили и адаптив (1440 px / 390 px) |
| `app.js` | Выбор экскурсии, расчёт суммы, проверка полей, отправка заявки |
| `Photo/` | Фотографии Светлогорска |
| `Reference/` | Примеры, по которым собрано оформление |

Сборка не нужна: это статические файлы.

- Цена: **350 ₽** с человека (`PRICE` в `app.js`)
- Максимум участников в заявке: **10** (`MAX_PEOPLE`)
- Экскурсии: Море Светлогорска, Озеро Тихое, Улицы Светлогорска, Отрадное и Волчий овраг
- Начало: 10:00, длительность: 2 часа, ежедневно
- Точка сбора: ул. Ленина, 11
- Почта для заявок: `vladimir19527352@gmail.com`
- Тема письма: «Заявка на экскурсию по Светлогорску»

## Как работает отправка

Заявка уходит через FormSubmit (`https://formsubmit.co/ajax/vladimir19527352@gmail.com`) — бэкенд не нужен, поэтому страница живёт на GitHub Pages.

**Обязательный шаг при первом запуске:** на `vladimir19527352@gmail.com` приходит письмо от FormSubmit со ссылкой «Activate Form». Без перехода по ней сервис отвечает `This form needs Activation` и письма не доставляются.

Если отправка не удалась (нет сети, форма не активирована), под кнопкой появляется ссылка «Открыть письмо в почтовой программе» с уже заполненным текстом заявки.

Локальный просмотр: `python -m http.server 8000`, затем `http://127.0.0.1:8000/`. Открывать `index.html` двойным щелчком нельзя — FormSubmit не работает на `file://`.

## Публикация на GitHub Pages

1. Создать репозиторий `vlad19527352/promenade` (публичный).
2. Загрузить `index.html`, `styles.css`, `app.js`, папку `Photo/`.
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, Folder: `/ (root)`.
4. Через минуту страница будет на `https://vlad19527352.github.io/promenade/`.

## Что осталось уточнить у владельца

- Условия отмены — сейчас на странице заглушка «Условия уточняются».
- Фотография гида — в письме упомянута, но в `Photo/` её нет.
- Телефон или мессенджер для блока контактов — сейчас указана только почта.
