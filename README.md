# Променад — экскурсии по Светлогорску

Одностраничный лендинг экскурсионного агентства: расписание четырёх прогулок, расчёт стоимости и заявка на почту владельца.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Разметка страницы |
| `styles.css` | Стили и адаптив (1440 px / 390 px) |
| `app.js` | Выбор экскурсии, расчёт суммы, проверка полей, отправка заявки |
| `Photo/` | Фотографии Светлогорска |
| `Reference/` | Примеры, по которым собрано оформление |

Сборка не нужна: это статические файлы.

## Данные страницы

Цена, лимит участников и названия маршрутов живут в разметке — скрипт читает их оттуда, поэтому дублировать значения в `app.js` не нужно.

| Параметр | Где задан | Значение |
|---|---|---|
| Цена | `data-price` на `#tourGrid` | **350 ₽** с человека |
| Максимум участников | `data-max` на `#tourGrid` | **10** |
| Названия экскурсий | `<h3 class="tour__title">` в карточках | Море Светлогорска, Озеро Тихое, Улицы Светлогорска, Отрадное и Волчий овраг |
| Ключ сервиса | `ACCESS_KEY` в `app.js`, скрытое поле в форме | Web3Forms |
| Почта для заявок | `OWNER_EMAIL` в `app.js`, футер | `vladimir19527352@gmail.com` |
| Тема письма | `SUBJECT` в `app.js` | «Заявка на экскурсию по Светлогорску» |

Начало в 10:00, длительность 2 часа, ежедневно, точка сбора — ул. Ленина, 11.

## Как работает отправка

Заявка уходит через Web3Forms (`https://api.web3forms.com/submit`) — бэкенд не нужен, поэтому страница живёт на GitHub Pages. Сервис работает и на `localhost`, и на опубликованном домене, активация по домену не требуется.

Ключ доступа (`access_key`) публичный: он виден в исходниках страницы, но отправить письмо на чужой ящик с ним нельзя.

Если отправка не удалась (нет сети, сервис недоступен, превышен лимит), под кнопкой появляется ссылка «Открыть письмо в почтовой программе» с уже заполненным текстом заявки — данные не теряются.

Без JavaScript форма тоже работает: у неё есть `action`, а нужные поля продублированы скрытыми `input`.

Локальный просмотр: `python -m http.server 8000`, затем `http://127.0.0.1:8000/`. Открывать `index.html` двойным щелчком нельзя — сервис не принимает заявки со страниц `file://`.

Бесплатный лимит Web3Forms — 250 заявок в месяц.

## Публикация на GitHub Pages

1. Создать репозиторий `vlad19527352/promenade` (публичный).
2. Загрузить `index.html`, `styles.css`, `app.js`, папку `Photo/`.
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, Folder: `/ (root)`.
4. Через минуту страница будет на `https://vlad19527352.github.io/promenade/`.

## Что осталось уточнить у владельца

- Условия отмены — сейчас на странице заглушка «Условия уточняются».
- Фотография гида — в письме упомянута, но в `Photo/` её нет.
- Телефон или мессенджер для блока контактов — сейчас указана только почта.
