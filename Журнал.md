## 11. Сбой при открытии index.html локально (24.11.2026)

> «отправка формы происходит при работе Koda Desktop. Захожу в локальную папку проекта и запускаю index.html — заявка не отправляется»

Причина: страница открыта по `file://`, а FormSubmit отклоняет такие запросы. Ответ API:

```json
{"success":"false","message":"Make sure you open this page through a web server, FormSubmit will not work in pages browsed as HTML files."}
```

CORS при этом не виноват: сервис отдаёт `Access-Control-Allow-Origin: *`, блокирует именно протокол.

Правка: при `window.location.protocol === 'file:'` форма сразу показывает понятное сообщение и ссылку на почту, не делая заведомо провальный запрос. Добавлено распознавание ответа FormSubmit про «web server».
